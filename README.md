# Networking Labs

Hands-on networking labs built in Cisco Packet Tracer while studying for CompTIA Network+, pairing Professor Messer's theory with practical configuration and troubleshooting. Each folder below is a separate, self-contained project.

## Projects

- [`ntp-and-static-routing/`](./ntp-and-static-routing/) — NTP synchronization (with failure/recovery testing) and static routing between two subnets, including systematic connectivity troubleshooting
- [`vpn-fundamentals/`](./vpn-fundamentals/) — GRE tunnel between two routers, demonstrating core VPN tunneling concepts

Each project folder contains its own README with the full write-up and the Packet Tracer topology file (.pkt) for that lab.

## Tools

- Cisco Packet Tracer
- Professor Messer's Network+ (N10-009) course
